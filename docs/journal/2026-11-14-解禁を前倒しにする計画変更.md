## 理由

- 運用者の都合で、検証（実機の実測と24時間稼働の実績づくり）を 11月中に終えることにした
- 001〜012 は 11-14 の時点で偽の LLM のテストが通り（011 は PR #15）、当初の M3（11-25〜12-02）の実装の作業が前倒しで終わっていた。解禁の前に用意すると決めていた手順書（006 の `deploy/README.md` と予行演習、002・005 の quickstart）も揃っている
- 11月の枠は月末で消えるので、AI解禁を早めると使える枠が増える（11-15〜11-30 で 3,000）

## 前倒しで変わること

- 実機での最初の確認（002 のスモークテスト）と VPS の配備を同じ日に行う。スモークテストで Pi から切り替えると決めた場合は、配備の前にコードを直すことになる。配備は `update.sh` で入れ替えられるので、切り替えの判断を待たずに配備してもよい
- 検証を 11月の枠 3,000 だけで行う。スモークテスト（10 以下）、ハーネスの調整、回帰評価（全件1回で 100〜250 の見積もり）、24時間稼働のデモ Issue を、`factory.toml` の `[budget]` で配分する
- VPS の無料期間は 11-28 で終わる。11-29 の最後の1日と、締切（12-16）・審査期間の稼働は、コンテストの要項を確かめて有料で延長するかを決める

# 2026-11-27 AI解禁と VPS解禁を 11-27 に移す

## 何を変えたか

11-15 に予定していた AI解禁・VPS解禁を行えないまま 11-27 になった。11-27 に両方を解禁し、実装と実機の調整を 11-27・11-28 の2日で終える計画に組み直した。

| 項目 | 変更前（11-14 の計画） | 変更後 |
|---|---|---|
| AI解禁・VPS解禁 | 11-15 | 11-27 |
| VPS の無料期間 | 11-15〜11-28 | 11-27〜12-10 |
| 実機の調整・回帰評価 | 11-15〜11-19（M3）、11-20〜11-29（M4） | 11-28 の1日 |
| 機能凍結 | 11-29 | 11-28 の夜 |
| 24時間稼働 | 11-20〜11-29 | 11-28 の夜から。11-30 までは 11月の枠、12-01 からは 12月の枠 |
| 記事 | 11-30〜12-16 | 11-29〜12-16 |
| 任意機能（`two-stage-command`・gVisor・通知） | 遅れたら削る | 作らない |

## 理由

- 11-14 の時点で 001〜012 は偽の LLM のテストが通っており、未完のタスクは実機での確認（002 の T019・T020・T035、007 の T033 の後半）だけ。手順書（`docs/解禁の日の手順.md`、`deploy/README.md`）も揃っているので、2日で流せる見込み
- 11月の枠 3,000 は 11-30 で消える。11-27〜11-30 の4日で使い切る前提で配分する（スモーク 10 以下、手元の計画〜判定 50 以下、調整 300 程度、回帰評価と検査役の比較 600 程度、残りを稼働のデモ Issue）
- VPS の無料期間が後ろにずれたので、11-14 の計画で問題だった「無料期間が 11-28 で切れる」は解消し、代わりに 12-11〜12-16 が無料期間の外になる

## 想定しているリスク

- スモークテストでツール呼び出しが安定せず、Pi から TanStack AI に切り替える場合、その実装で 11-28 の大半を使う。その場合も VPS の配備は 11-27 に行い（`update.sh` で入れ替えられる）、回帰評価の検査役比較は 12月の枠に回す

## まだ分かっていないこと
